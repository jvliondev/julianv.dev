# Signature interactions and delivery order

## P0 — delivered in the local implementation

- User-controlled vault entry with bolt, vent, and door states; Skip entry sequence remains available during the sequence.
- Six distinct project bays with different authored mechanisms and accents.
- Xondry and every other project open a project-details route; concept visuals are labeled clearly.
- A single-chamber reducer handles release, venting, opening, reveal, and safe close. Per-phase timers clean up on state change or component unmount.
- Escape and close return focus; URL hash selection makes browser back/forward consistent.
- The homepage always uses the interactive chambers, while Work lists all six projects. Reduced-motion preferences remove sequence timing and reveal content immediately.
- All copy and controls are real DOM. The scene is an authored 2.5D enhancement and requires no WebGL.
